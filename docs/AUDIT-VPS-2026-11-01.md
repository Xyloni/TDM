- 803 записи успешного импорта с 00:25:03 до 00:25:25, около 22 секунд.

- Для 4031 последовательного интервала меньше двух минут: медиана 59,969 секунды,

- Для 102 завершений награды следующий переход в watching занял 2,602–4,045 секунды,

  Запись прогресса выполняется при изменениях, поэтому отсутствие такой записи
  само по себе не означает отсутствия опроса.
- 3480 предупреждений accounts и 1251 предупреждение overview связаны с
  `context canceled`, а не с недействительностью токенов.

## Исправления по обратной связи

- Проверка авторизации различает отсутствующую сессию и ошибку её чтения.
  Первоначальный вход не порождает уведомления о сбое и последующем восстановлении.
  Отменённые проверки и устаревшие проверки удалённого или повторно вошедшего
  аккаунта не должны заменять актуальное состояние авторизации.
- Отмена запроса интерфейса прекращает обход списка аккаунтов; ожидаемая отмена
  не записывается как ошибка поиска сессии.
- В окне кампании добавлено обратимое исключение конкретной награды для всех
  существующих и будущих аккаунтов данной платформы. Оно доступно без ячеек
  аккаунтов и не подменяет награду фиктивным получением. Настоящие предварительные
  условия Twitch/Kick сохраняются. Текущий просмотр исключённой награды прерывается
  запросом переключения, без ожидания очередного минутного тика; уже выполняющийся
  сетевой вызов завершается в обычном порядке.
- Интерфейс переименован в Pzhomba Pump. Исходный многоразмерный ICO хранится
  в `assets/img/pzhomba-pump.ico`, остальные иконки получены из него.

Для дальнейшего сравнения нужен сеанс без удаления/импорта и ручного изменения
планов, с известными стартовыми минутами и одной активной группой. Сравнивать
следует прирост, а не абсолютные числа в интерфейсе.

## English

**Pzhomba Pump brings faster account management, clearer farming diagnostics and Telegram controls.**

### 🌱 Added

- **Farming uniformity dashboard.** Compare confirmed gains and speed over 15/30 minutes, filter accounts and see waiting reasons and recent channel switches.
- **Group completion forecast.** See how many accounts have finished, the estimated remaining time and which members are holding up the group. Missing data stays visible.
- **Telegram tools.** Use `/help`, `/status`, `/groups` and `/lagging`, receive pinned group handoffs, and follow problems through one message that updates as conditions change.
- **Slow-accrual recovery.** Confirm sustained speed below 90% over a 15-minute window before changing channels, with a cooldown between attempts.
- **Global reward exclusions.** Exclude or restore a reward for all existing and future accounts without faking a platform claim.
- **Full session logs.** Download the whole current session from Health. Each app start begins a fresh log.

### ⚙️ Changed

- **Pzhomba Pump branding.** Updated the interface name, logo and icons, plus a refreshed bilingual README covering the current features and deployment options.
- **Faster account operations.** Import Twitch accounts with up to 16 concurrent validation workers and remove all accounts in one transaction. Miners pause for account maintenance and resume afterward.
- **Independent Twitch playback.** HLS refreshes every 20 seconds while the minute beacon remains at 60 seconds.

### 🐛 Fixed

- **Duplicate reward processing.** A watch rescan leaves the active reward to the normal claim flow, preventing repeated claim requests and notifications. The live follow-up recorded 700 unique claims with no duplicate account/reward entries.
- **Import notification spam.** Accounts awaiting their first login no longer generate false authentication outage and recovery alerts.
- **Temporary inventory failures.** Failed or incomplete inventory reads no longer unnecessarily interrupt a working watch or skip the current reward.
- **Slow requests and cleanup.** Bounded watch requests, safer redirect validation and more complete account cleanup improve reliability.

### 🔥 Removed

- **Duplicate Windows launcher.** Use `run-miner.bat` as the Windows entry point.

## Русский

**Pzhomba Pump: быстрое управление аккаунтами, контроль равномерности фарма и команды Telegram.**

### 🌱 Добавлено

- **Экран равномерности фарма.** Сравнение фактического прироста и скорости за 15/30 минут, фильтры аккаунтов, причины ожидания и недавние смены каналов.
- **Прогноз завершения группы.** Количество закончивших аккаунтов, примерный остаток времени и участники, задерживающие переход. Недостаток данных показывается явно.
- **Инструменты Telegram.** Команды `/help`, `/status`, `/groups`, `/lagging`, закреплённые переходы групп и сводка проблем, которая обновляет одно сообщение.
- **Восстановление медленного начисления.** Смена канала после подтверждённой скорости ниже 90% за 15-минутное окно, с паузой между попытками.
- **Глобальные исключения наград.** Исключение и возврат предмета для текущих и будущих аккаунтов без подмены настоящего получения на платформе.
- **Полные журналы сеанса.** Скачивание всего текущего лога из раздела здоровья. Каждый запуск приложения начинает новый журнал.

### ⚙️ Изменено

- **Название и оформление Pzhomba Pump.** Обновлены имя в интерфейсе, логотип и иконки. Двуязычный README оформлен заново и описывает актуальные функции и варианты запуска.
- **Быстрые операции с аккаунтами.** Импорт Twitch использует до 16 параллельных проверок, массовое удаление выполняется одной транзакцией. На время обслуживания аккаунтов майнеры приостанавливаются и затем возобновляют работу.
- **Независимый просмотр Twitch.** HLS обновляется раз в 20 секунд, минутный маяк сохраняет интервал 60 секунд.

### 🐛 Исправлено

- **Повторная обработка наград.** Сканирование оставляет активную награду штатному циклу получения, устраняя повторные запросы и уведомления. Контрольный живой прогон дал 700 уникальных получений без повторов аккаунт/награда.
- **Спам при импорте.** Аккаунты до первого входа больше не вызывают ложные уведомления о сбое и восстановлении авторизации.
- **Временные ошибки инвентаря.** Неудачные и неполные ответы больше не прерывают исправный просмотр без необходимости и не пропускают текущую награду.
- **Долгие запросы и очистка.** Ограничено время запросов просмотра, усилена проверка перенаправлений и дополнена очистка рабочих данных аккаунтов.

### 🔥 Удалено

- **Дублирующий Windows-батник.** Для запуска используется `run-miner.bat`.
